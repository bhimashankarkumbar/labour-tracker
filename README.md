# Labour Tracker

A full-stack workforce and job site management system for tracking daily labour attendance, wages, payments, and site expenses.

---

## Features

- **Worker Management**: Manage worker profiles, daily wage rates, and outstanding balances.
- **Site & Attendance Tracking**: Track work sites and record daily attendance (full day, half day, overtime).
- **Payments & Expenses**: Log wage disbursements, advance payments, and project expenses.
- **Analytics Dashboard**: Real-time overview of expenses, labour costs, and project metrics.
- **Secure Authentication**: JWT-based authentication and secure session handling.

---

## Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS, Recharts, Lucide React, Axios
- **Backend**: Java 21, Spring Boot 3, Spring Security (JWT), Spring Data JPA
- **Database**: MySQL

---

## Getting Started

### Backend

```bash
cd backend
mvn spring-boot:run
```

- **URL**: [http://localhost:8080](http://localhost:8080)

### Frontend

```bash
cd frontend
npm install
npm run dev
```

- **URL**: [http://localhost:5173](http://localhost:5173)
